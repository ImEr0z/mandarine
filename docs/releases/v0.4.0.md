# Mandarine 0.4.0 : Mises à jour automatiques

*23 octobre 2026*

- 🔄 **Mises à jour au démarrage** : Mandarine cherche une nouvelle version à chaque lancement. Tu peux aussi la chercher à la main depuis le menu.
- 🤫 **Lancement discret** : Mandarine peut démarrer sans rien afficher et rester dans la barre des tâches.
- 🖼️ **Icônes à jour** : Les icônes de Mandarine dans Windows se rafraîchissent après une installation ou une mise à jour.

## Télécharger

- **`MandarineApp-win-Setup.exe`** : l'installeur. Mandarine se met ensuite à jour toute seule.
- **`Mandarine-win-x64.zip`** / **`Mandarine-win-arm64.zip`** : l'exécutable seul, sans installation.
