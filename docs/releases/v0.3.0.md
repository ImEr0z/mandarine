# Mandarine 0.3.0 : Un menu plus simple

*23 octobre 2026*

- 🖱️ **Un clic suffit** : Le clic gauche sur l'icône de la barre des tâches ouvre le menu.
- 🧹 **Zone de dépôt retirée** : La petite zone où l'on déposait les fichiers n'existe plus : utilise la roue.

## Télécharger

- **`MandarineApp-win-Setup.exe`** : l'installeur. Mandarine se met ensuite à jour toute seule.
- **`Mandarine-win-x64.zip`** / **`Mandarine-win-arm64.zip`** : l'exécutable seul, sans installation.
