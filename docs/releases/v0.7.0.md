# Mandarine 0.7.0 : PDF cherchable et réglages par type

*novembre 2026*

- 🔍 **PDF cherchable** : Un PDF scanné ou une photo de page devient un PDF dont on peut chercher et copier le texte. Le texte est lu sur ton PC, avec Windows.
- 🩹 **Réparer un PDF** : Un PDF abîmé est réécrit en copie propre, prête à s'ouvrir.
- 🎛️ **Réglages par type de fichier** : Pour les images, les PDF et le reste : dossier de destination, qualité, taille maximale, résolution des pages et un texte ajouté au nom.
- 🕘 **Conversions récentes** : Retrouve les derniers fichiers créés, avec une miniature, depuis le menu de l'icône. Un clic les ouvre.
- 🪄 **Nouveautés plus nettes** : La page Nouveautés s'ouvre directement au centre, sans sauter.

## Télécharger

- **`MandarineApp-win-Setup.exe`** : l'installeur. Mandarine se met ensuite à jour toute seule.
- **`Mandarine-win-x64.zip`** / **`Mandarine-win-arm64.zip`** : l'exécutable seul, sans installation.
